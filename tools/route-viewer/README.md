# Visor local de rutas BMW E87

Abre el acceso directo **BMW E87 - Rutas de conducción** del escritorio. El visor usa automáticamente los cinco ficheros OSM de su carpeta `data`; solo hay que pulsar **Cargar logs del USB** y elegir `E:\IDRIVE_DEBUG`.

Los segmentos locales son copias exactas, verificadas por SHA-256, de los ficheros incluidos en la release GitHub `data-v20261114-173309`. Las fichas de la derecha muestran horario, duración, distancia y velocidades máxima/mínima que hayan quedado registradas en el GPS. El desplegable solo ofrece fechas con rutas. **Todas las rutas** oscurece las calles recorridas por más trayectos.

Para mostrar nombres de calles y comercios usa el mapa base estándar de OpenStreetMap, que necesita conexión a Internet. Solo se piden las teselas visibles; el servidor local no envía los archivos de logs. OpenStreetMap recibe el área aproximada del mapa que estás viendo. Los datos de rutas permanecen en el navegador.
