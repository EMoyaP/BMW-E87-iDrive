# Política de seguridad

## Versiones compatibles

El proyecto está en fase de validación de hardware. Solo la rama `main` recibe correcciones.

## Informar de un problema

No publiques una vulnerabilidad explotable, credenciales, APK OEM extraídas, números de serie, IMEI, direcciones MAC
ni diagnósticos completos en un issue público.

Utiliza la opción **Report a vulnerability** de GitHub Security Advisories cuando esté disponible en el repositorio.
Incluye una descripción, pasos mínimos para reproducirla, impacto y versión afectada. El mantenedor confirmará la
recepción y coordinará una corrección antes de hacer públicos los detalles.

## Seguridad del vehículo

Si una prueba afecta a cámara, PDC, climatización, audio, mandos del volante o comportamiento de la MCU/CANBUS, detén
la aplicación y la prueba. No continúes circulando para recopilar datos.
